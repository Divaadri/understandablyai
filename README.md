# Understandably

### AI-Powered Classroom Digital Twin

Understandably is an AI-powered digital classroom twin that analyzes classroom layouts, evaluates individual seats, and provides intelligent recommendations to improve the learning environment.

The Week 5 prototype focuses on refining the user experience and improving the reliability, clarity, and visual presentation of the original prototype based on real user testing and feedback collected during Week 4.

Designed for the Qutuhal InnovateX 2.0 2026 Build Sprint.

## Key Features

- AI-powered classroom analysis
- Interactive digital classroom twin
- Seat-wise evaluation
- AI-generated recommendations
- Specialized Seat Analysis
- Bests — identification of the best seats
- Classroom-wise analysis
- Live classroom analysis
- Visual analysis overlays
- Responsive web interface
- Powered by Google Gemini

## Week 5 Improvements

Based on feedback from 10 real users during Week 4, the prototype was refined with a focus on:

- Simplifying and decluttering the interface
- Improving classroom map and seat detection
- Refining AI-generated recommendations
- Improving API error handling and reliability
- Improving the clarity of visual overlays
- Improving the overall visual design and user experience

[Open Understandably](https://understandablyai.netlify.app/)

> The AI analysis depends on external AI services and network connectivity. If an analysis attempt fails or takes longer than expected, please try again after a short wait.

> If you open the application directly using a `file:///` URL, it may not function correctly because of browser security restrictions. Run the project through a local web server such as Live Server in VS Code or `python -m http.server`.

## Usage

1. Launch the application.
2. Select a classroom or upload a video/image.
3. Start the classroom analysis.
4. Wait for the AI analysis to complete.
5. Review the AI-generated recommendations.
6. Select individual seats to view their detailed analysis.
7. Explore **Bests** to identify the strongest seats.
